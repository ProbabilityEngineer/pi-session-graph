# Add project-focused timeline and neighborhood reports

Support one-project-at-a-time and one-session-at-a-time focused reports so the graph pack can move from global summaries to suspicious clusters to focused subgraphs.

## Acceptance Criteria

- Provide a way to generate or link project timeline reports filtered to a single repo/project.
- Include related jumps as side links/annotations rather than drawing the full global edge set.
- Provide session neighborhood graph generation for a selected session/path/id with ancestors, descendants, and nearby jumps.
- Report index links from hotspot/repo jump entries into focused project/session artifacts where practical.
- Filenames/titles clearly include the project/session identifier and scope.
